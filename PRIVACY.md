# Privacy policy

This plugin is published by ChartQuery (https://www.chartquery.com).

## What the plugin sends

When a tool runs, the plugin sends the chart config or data, the diagram source or description, or the text to encode to the ChartQuery API at `https://api.chartquery.com`, with your API key in the `x-api-key` header. When you save the API key in Dify, the plugin checks it with one request that costs no credits.

The plugin calls no other host.

## What the plugin stores

The plugin stores nothing. It keeps no logs, files or caches. Dify stores the API key you enter, as it does for every plugin credential. ChartQuery stores the images it renders behind public links until they expire (3 days on the free plan, 6 months on paid plans).

## What ChartQuery does with the data

ChartQuery processes requests to return results and to count credits on your account. See the ChartQuery privacy policy: https://www.chartquery.com/privacy
